# yocto

Planned recipes for runtime/backend/feature/model IPK packages.

- **Status:** planned — no installable package yet

## Responsibility

- Package runtime, backend, feature and model IPKs independently.
- Pin compatibility and coordinate coherent update with FW.

## Limits and next work

- Independent packaging does not imply one process per feature.
- Pin board image, models, cameras, FPS, ROI limits and KPIs per workload profile.
