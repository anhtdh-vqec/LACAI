# ocr

Reserved plate/OCR boundary for traffic workflows.

- **Status:** planned — not implemented
- **Naming registry:** `ocr`
- **Depends on:** vehicle detection, association and lane/calibration contracts

## Limits and next work

- Traffic order: vehicle count/class, lane/direction, plate OCR association, calibrated speed.
- Do not infer legal speed from pixel displacement without calibration and validation.
